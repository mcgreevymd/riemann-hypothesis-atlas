The files in this directory are the research bundle archived for the v1.21 insertion. They are a historical source. The public atlas leads with the corrected synthesis, and [AUDIT.md](AUDIT.md) overrides both that synthesis and every file in `notes/` when they disagree.

Binding order:

1. `AUDIT.md` is the independent audit of 8 Nov 2026. It overrides `SYNTHESIS.md` and `notes/`.
2. Do not quote a scratch note that AUDIT §D corrects unless the correction is stated with it. In particular: residues belong to the completed zeta, not ξ; e^⊥ is not E0; there is one negative direction off E0, not two; the signature of S uses the constrained certificate; X¹⁰ − 1 is the boundary class δ(1), not the Eisenstein class; K₀ has no RG parameter; “Lemma A” is a Ritz value; S ≈ ±400 was a basis artifact; N = T₂ + 24 is the nilpotent element mod 691; the explicit-formula table that uses zeros is diagnostic only; the vertical-line step of the probe argument is a sketch; q′(0) > 0 is not passivity; the KMS kernel is not K_q.
3. Some notes are written in the second person. They are archived here and are not quoted in the front matter.
4. `ref/atlas.json` is the v1.20 baseline used to build the delta (1044 concepts, 2051 relations). The live repository matched that baseline before the insertion. It is not a second public atlas.
5. The integration prompt that packed this bundle is not part of the repository.
